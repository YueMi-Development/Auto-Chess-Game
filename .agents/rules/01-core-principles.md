# Core Principles

1. Readability over cleverness.
2. Maintainability over speed of writing.
3. Explicit behavior over implicit behavior.
4. Simplicity over unnecessary abstraction.
5. Consistency is mandatory.
6. If it is hard to understand, it is wrong.
7. Open-source root repo: no secrets, internal hostnames, or private submodule details in public docs.
